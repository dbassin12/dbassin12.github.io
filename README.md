# dbassin12.github.io

The personal site of David Bassin, a high school teacher who builds learning tools with AI and helps other teachers use AI well.

Live at [dbassin12.github.io](https://dbassin12.github.io/). Static HTML pages, no build step:

- `index.html`: the portfolio (selected work, how I work, teaching teachers, the home AI lab, about)
- `David_Bassin_Resume.pdf`: one-page resume for ed-tech roles
- `David_Bassin_Resume_School.pdf`: one-page resume for school roles
- `econ-arcade-case-study/`, `shift-happens-guide/`, `ai-guidelines/`, `ai-workshop/`: work samples
- `assets/page.css`: shared style for the work samples
- `404.html`, `sitemap.xml`, `robots.txt`: site basics

Consulting site: [bassinconsulting.com](https://www.bassinconsulting.com/)
